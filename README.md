# IMAGE EDITOR

A browser-based image editor built using HTML, CSS, and JavaScript.

## Features

* Brightness Filter
* Contrast Filter
* Saturation Filter
* Hue Rotation
* Blur Effect
* Grayscale
* Sepia
* Opacity Control
* Invert Filter
* Preset Filters
* Download Edited Image

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Canvas API
